💡 What to Notice

  • Both services extract the same fields from structured documents like invoices and receipts.
  • CU prebuilt models are built on DI's technology, with added GenAI postprocessing for improved accuracy.
  • Compare confidence scores — CU often matches or exceeds DI's confidence.
  • Microsoft recommends CU for new projects; DI remains solid for existing deployments.
📚 Behind the Scenes — How This Works

☁️ Azure Resources Required

  • Azure AI Services (kind: AIServices)
  • Prebuilt models are included — no training or deployment needed
  • Both DI and CU share the same prebuilt model names
  • Managed Identity for auth (no API keys)

🔗 REST API Endpoints

DI: POST /formrecognizer/documentModels/{model_id}:analyze
CU: POST /contentunderstanding/analyzers/{analyzer_id}:analyze

Models: prebuilt-invoice, prebuilt-receipt, prebuilt-layout, prebuilt-read

🐍 Python SDK Code

DI Prebuilt
poller = client.begin_analyze_document(
    model_id="prebuilt-invoice",
    body=AnalyzeDocumentRequest(
        bytes_source=file_bytes
    ),
)
result = poller.result()

# Access extracted fields
for field_name, field in result.documents[0].fields.items():
    print(f"{field_name}: {field.value} ({field.confidence:.0%})")
CU Prebuilt
poller = client.begin_analyze(
    analyzer_id="prebuilt-invoice",
    body=file_bytes,
    content_type="application/octet-stream",
)
result = poller.result()

# Access extracted fields
for content in result["contents"]:
    for field_name, field in content["fields"].items():
        print(f"{field_name}: {field['valueString']} ({field['confidence']:.0%})")
