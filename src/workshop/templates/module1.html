📚 Behind the Scenes — How This Works

☁️ Azure Resources Required

  • Azure AI Services (kind: AIServices) — single multi-service resource
  • Serves both DI and CU from the same endpoint
  • Managed Identity for auth (no API keys)
  • Region: East US (or any supported region)

🔗 REST API Endpoints

DI: POST /formrecognizer/documentModels/prebuilt-layout:analyze
CU: POST /contentunderstanding/analyzers/prebuilt-layout:analyze

🐍 Python SDK Code

Document Intelligence
from azure.ai.documentintelligence import (
    DocumentIntelligenceClient,
)
from azure.identity import DefaultAzureCredential

client = DocumentIntelligenceClient(
    endpoint=endpoint,
    credential=DefaultAzureCredential(),
)
poller = client.begin_analyze_document(
    model_id="prebuilt-layout",
    body=AnalyzeDocumentRequest(
        bytes_source=file_bytes
    ),
)
result = poller.result()
Content Understanding
from azure.ai.contentunderstanding import (
    ContentUnderstandingClient,
)
from azure.identity import DefaultAzureCredential

client = ContentUnderstandingClient(
    endpoint=endpoint,
    credential=DefaultAzureCredential(),
)
poller = client.begin_analyze(
    analyzer_id="prebuilt-layout",
    body=file_bytes,
    content_type="application/octet-stream",
)
result = poller.result()

    --name my-ai-services \
    --resource-group my-rg \
    --kind AIServices \
    --sku S0 \
    --location eastus

# Install the Python SDKs
pip install azure-ai-documentintelligence \
    azure-ai-contentunderstanding azure-identity
